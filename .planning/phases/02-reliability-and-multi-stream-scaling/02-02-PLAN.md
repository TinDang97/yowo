```python
def _run_gpu(self, tensor: PreprocessedTensor, frames: list[Frame]) -> tuple[NDArray[np.float32], float]:
    with self._infer_lock:
        if self._feature_cache is not None and frames:
            sid = frames[0].source_id
            if sid:
                self._backend.set_source_id(sid)
        t0 = time.perf_counter()
        raw_output = self._backend.infer(tensor)   # <-- replace with self._infer_with_retry(tensor)
        elapsed_ms = (time.perf_counter() - t0) * 1000.0
        self._metrics.record_inference(elapsed_ms, batch_size=tensor.batch_size, frame_time=t0)
    return raw_output, elapsed_ms
```

    - _oom_monitor_loop(): while not self._oom_stop.wait(timeout=5.0): reads torch.cuda.memory_reserved(device_index) / torch.cuda.get_device_properties(device_index).total_memory; calls _apply_oom_recovery(pct); exceptions are caught and logged at WARNING, loop continues
    - _apply_oom_recovery(pct): thresholds _OOM_TIER1=0.80, _OOM_TIER2=0.90, _OOM_TIER3=0.95, _OOM_CLEAR=0.75
