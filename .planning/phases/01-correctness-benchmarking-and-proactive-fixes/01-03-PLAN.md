    1. In `src/yowo/cli/_main.py`, add `benchmark` subcommand:
       ```python
       @cli.command("benchmark")
       @click.option("--model", "-m", required=True, help="Model name, e.g. yolo11n or yolo11n-cls")
       @click.option("--data", required=True, type=click.Path(), help="Path to dataset root (COCO or ImageNet)")
       @click.option("--format", "formats", default=None, help="Comma-separated formats: pytorch,onnx,trt,openvino")
       @click.option("--subset", default=None, type=int, help="Evaluate on first N images only")
       @click.option("--json", "json_output", is_flag=True, help="Output results as JSON")
       @click.option("--output", "-o", default=None, type=click.Path(), help="Write JSON results to file")
       ```

    2. CLI handler logic:
       a. Validate --data path exists. If not, detect whether model is detection or classification from model name (contains "-cls" suffix).
          - Detection: print COCO download instructions: "Expected: {path}/val2017/ and {path}/annotations/instances_val2017.json. Download from: https://cocodataset.org/#download"
          - Classification: print ImageNet download instructions: "Expected: {path}/val/n01440764/*.JPEG (torchvision ImageFolder layout). Download from: https://image-net.org/download.php"
       b. Try to import benchmark module. If pycocotools or rich not available, raise click.UsageError with: "Benchmark requires optional dependencies. Install with: uv add yowo[benchmark]"
       c. Call `run_benchmark(model=model, data=data, formats=formats, subset=subset, json_output=json_output)`
       d. If --json or --output: get JSON dict from run_benchmark, serialize with json.dumps(indent=2)
          - If --output: write to file, print "Results written to {path}"
          - If --json (no --output): print to stdout
       e. If neither --json nor --output: run_benchmark handles rich table rendering internally

    3. Update `src/yowo/benchmark/__init__.py` `run_benchmark()` if needed to ensure the return type works for both table rendering (side effect) and JSON output (return value).

    4. Write `tests/unit/test_benchmark_cli.py` using `click.testing.CliRunner`:
       - Test help output contains all options
       - Test missing --data with mocked benchmark import
       - Test invalid path shows download instructions
       - Test --json flag (mock run_benchmark to return sample dict)
       - Test --output writes file (use tmp_path fixture)
       - Test --format passes correct filter
       - Test --subset passes correct limit
       - All tests mock the actual benchmark execution (no real model loading)

    NOTE on CORR-04/05/06: These requirements (export correctness on CUDA server, Jetson, Intel NUC) are validated by RUNNING `yowo benchmark --model X --data /path --format onnx` (or trt/openvino) on the target hardware.
