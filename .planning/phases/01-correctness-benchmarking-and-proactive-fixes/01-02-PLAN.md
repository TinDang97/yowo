    3. Create `src/yowo/benchmark/_evaluator.py` with two main functions:

       a. `evaluate_coco_map(gt_ann_path: str | Path, predictions: list[dict], subset: int | None = None) -> dict[str, float]`:
          - Uses `pycocotools.coco.COCO` to load ground truth annotations
          - Uses `coco_gt.loadRes(predictions)` to load detections
          - Runs `COCOeval(coco_gt, coco_dt, "bbox")` -> evaluate() -> accumulate() -> summarize()
          - Returns dict with keys: `mAP_50_95`, `mAP_50`, `mAP_75`
          - CRITICAL: Include `YOLO_TO_COCO` category mapping array (80 entries mapping YOLO 0-79 to COCO category IDs). Apply this mapping when converting YOWO BoundingBox detections to COCO result format.
          - Include helper `detections_to_coco_results(detections: list[Detection], image_ids: list[int]) -> list[dict]` that converts YOWO Detection objects to COCO format dicts `{image_id, category_id, bbox: [x,y,w,h], score}`. Must convert xyxy to xywh and map YOLO class_id to COCO category_id.

       b. `evaluate_imagenet_accuracy(predictions: list[tuple[int, int]], top_k: int = 1) -> dict[str, float]`:
          - Takes list of (predicted_class_id, ground_truth_class_id) pairs
          - Computes top-1 accuracy: `correct / total`
          - Returns dict with keys: `top1_accuracy`, `total`, `correct`

       c. `load_coco_dataset(data_path: str | Path, subset: int | None = None) -> tuple[list[Path], list[int], str]`:
          - Expects COCO root dir containing `val2017/` and `annotations/instances_val2017.json`
          - Validates directory structure, raises clear error with expected layout if wrong
          - Returns (image_paths, image_ids, annotation_path)
          - If subset is set, return first N images only

       d. `load_imagenet_dataset(data_path: str | Path, subset: int | None = None) -> tuple[list[Path], list[int]]`:
          - Expects ImageNet val dir with class folders: `val/n01440764/*.JPEG`
          - Walks folders, maps folder name to class index (sorted alphabetically = standard torchvision convention)
          - Returns (image_paths, class_labels)
          - If subset is set, return first N images only

    4. Create `src/yowo/benchmark/_comparison.py` with:
       - `run_ultralytics_benchmark(model_name: str, data_path: str | Path, task: str) -> dict | None`:
         - Try to import ultralytics. If not available, return None.
         - Load YOLO model, run val() on dataset
         - Return dict with mAP/accuracy metrics
         - Wrap in try/except: if ultralytics fails, log warning and return None

       a. `@dataclass` `BenchmarkResult`:
          ```python
          @dataclass
          class BenchmarkResult:
              format: str           # "pytorch", "onnx", "tensorrt", "openvino"
              map_50_95: float | None  # None if no dataset provided
              map_50: float | None
              fps_avg: float
              latency_p50_ms: float
              latency_p95_ms: float
              latency_p99_ms: float
              model_size_mb: float
              device: str
              num_images: int
          ```

       b. `run_single_backend(model_spec: ModelSpec, backend_type: BackendType, images: list[Path], image_ids: list[int] | None, gt_ann_path: str | None, task: str, warmup_passes: int = 10) -> BenchmarkResult`:
          - Create engine (DetectionEngine or ClassificationEngine based on task)
          - Load engine
          - Run warmup_passes dummy inferences (discard results and timing)
          - Run inference on all images, collecting:
            - Per-image latency (time.perf_counter around detect()/classify())
            - Detection/classification results
          - Compute FPS = num_images / total_time
          - Compute latency percentiles from per-image latencies
          - If gt_ann_path provided (detection): convert results to COCO format, call evaluate_coco_map()
          - If classification: compute top-1 accuracy
          - Get model file size from weights path
          - Return BenchmarkResult

          - Determine available backends (check which are importable)
          - If formats filter provided, only test those
          - For each backend: try run_single_backend(), catch BackendLoadError/DependencyError, log skip, continue
          - Return list of results
