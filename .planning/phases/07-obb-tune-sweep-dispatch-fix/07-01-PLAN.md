<objective>
Close INT-C1: `tune/_sweep.py._measure_config()` hardcodes `InferenceConfig` + `DetectionEngine`
for all tasks. When `yowo tune --model yolo11n-obb` runs, every configuration fails at warmup
because `DetectionEngine` validates output shape for detection (`(B, 4+nc, A)`) while the OBB
head emits `(B, 4+nc+1, A)`. All sweep results are skipped and no profile is saved.

Purpose: Enable OBB models to be auto-tuned via `yowo tune --model yolo11n-obb`, closing the
final functional gap in the v2.3 milestone.

Output:
- `src/yowo/tune/_sweep.py` — `_measure_config` with `if task == "obb"` branch using `OBBConfig`
  + `OBBEngine`, else branch keeping existing `InferenceConfig` + `DetectionEngine`; callable
  alias `infer_fn` used before warmup/measure loops
- `tests/unit/test_sweep.py` — `TestMeasureConfigDispatch` class with two regression tests
  verifying correct engine dispatch for each task type
</objective>

```python
def _measure_config(
    spec: ModelSpec,       # spec.task == "obb" | "detect" | "classify"
    hw: HardwareProfile,
    backend: BackendType,
    precision: Precision,
    batch_size: int,
    warmup_frames: int,
    measure_frames: int,
) -> float:
    # Currently: always uses InferenceConfig + DetectionEngine (bug)
    from yowo.config import InferenceConfig
    from yowo.engine import DetectionEngine

    config = InferenceConfig(
        model_family=spec.family,
        model_size=spec.size,
        num_classes=spec.num_classes,
        backend=backend,
        precision=precision,
        batch_size=batch_size,
    )
    engine = DetectionEngine(config)
    pixels = np.zeros((640, 640, 3), dtype=np.uint8)
    frames = [Frame(pixels=pixels)]

    try:
        engine.load()
        for _ in range(warmup_frames):
            engine.detect(frames)          # BUG: OBBEngine has no .detect()
        t0 = time.monotonic()
        for _ in range(measure_frames):
            engine.detect(frames)          # BUG: OBBEngine has no .detect()
        elapsed = time.monotonic() - t0
        return measure_frames / elapsed
    finally:
        engine.close()
```
