  <behavior>
    - run_batch(config: BatchConfig, engine: DetectionEngine) -> int (exit code 0/1/2)
    - Startup: collect source files; check for checkpoint at output/.yowo_checkpoint.json; if checkpoint exists and not no_resume: load completed set, open results.jsonl in append mode, print "Resuming: {N}/{total} files done"; else: completed = set(), open results.jsonl in write mode
    - output_dir created if not exists
    - Per image file: cv2.imread or PIL; engine.detect(frame); write JSONL row {"path": str(file), "detections": detection.to_dict()}; if not no_annotate write annotated frame to output/frames/{stem}_annotated{ext}
    - Per video file: use ThreadedFrameReader; per frame: engine.detect(); collect detections; write JSONL row grouped by source file with all frame detections; if not no_annotate write frames to output/frames/{video_stem}/{frame_idx:06d}.jpg
    - File open failure: log warning, write to output/errors.log, continue; increment error_count
    - Checkpoint: flush every 100 files OR 30 seconds via threading.Timer (restart timer each flush); flush on completion
    - FPS: rolling 5s window using collections.deque of (timestamp, frames_processed) pairs; fps = sum of frames in last 5s / 5.0
    - Rich Progress columns: SpinnerColumn, BarColumn, TaskProgressColumn, files done/total TextColumn, FPS TextColumn (f"{fps:.1f} FPS"), TimeRemainingColumn
    - Final summary print: "Completed: {total_files} files | {total_frames} frames | {elapsed:.1f}s | {avg_fps:.1f} FPS avg | Output: {output_dir}"
    - Return 0 if error_count == 0, 1 if 0 < error_count < total_files, 2 if fatal (uncaught exception)
    - test_checkpoint_resume_skips_completed: mock engine, create 3-file dir, write checkpoint with 1 completed, assert engine only called for 2 files
    - test_uses_profile_batch_size: BatchConfig with engine already configured; assert engine.detect called with correct frame shape
    - test_progress_columns: mock rich.progress.Progress, assert task fields include fps key
    - test_errors_written_to_log: mock cv2.imread to raise on one file, assert errors.log contains that filename
  </behavior>
