  <behavior>
    - compute_fingerprint(hw: HardwareProfile) -> str: GPU path returns 8-char hex of SHA-256("{gpu.name}|{gpu.memory_total_mb * 1024 * 1024}|{hw.libraries.cuda_version or 'none'}"); CPU path returns 8-char hex of SHA-256("cpu|{os.cpu_count()}|{platform.platform()}")
    - save_profile(profile: TuneProfile, path: Path | None = None): writes to path or ~/.cache/yowo/profiles/{fingerprint}/{model}.yaml; creates parent dirs; writes to .tmp then os.replace (atomic)
    - load_profile(model: str, hw: HardwareProfile, path: Path | None = None) -> TuneProfile | None: returns None if file missing; returns None on KeyError/ValueError/YAMLError (corrupt); checks profile.fingerprint == compute_fingerprint(hw); if mismatch, logs WARNING "Hardware changed since last tune. Run `yowo tune --model {model}` to update profile." and returns None
    - TuneProfile fields: model: str, backend: str, batch_size: int, precision: str, fps_achieved: float, tuned_at: str (ISO8601), fingerprint: str
    - test_compute_fingerprint_gpu: mock HardwareProfile with GPU, assert result is 8-char hex string
    - test_compute_fingerprint_cpu: mock HardwareProfile with no GPU (primary_gpu=None), assert result is 8-char hex string
    - test_save_load_roundtrip: save profile to tmp_path, load it back, assert all fields equal
    - test_load_missing_returns_none: load from nonexistent path returns None
    - test_load_corrupt_returns_none: write invalid YAML, load returns None
    - test_fingerprint_mismatch_warns_and_returns_none: save profile with fingerprint "aabbccdd", load with hw producing different fingerprint, assert returns None and warning logged
  </behavior>
