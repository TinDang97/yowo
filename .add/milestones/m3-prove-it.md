## CARD
goal: Every claim yowo makes about inference has a runnable, committed check behind it.
why: 2175 tests and 80% line coverage prove things about mocks. The product's entire value rests on evidence that does not exist in the repository. AMENDED 2026-09-13, measured rather than restated, because m2 and m1 closed three of the five claims this milestone was written on and building against a stale motivation is how a node ends up justifying work the repo already did: (i) "No test executes a real backend forward pass" is FALSE — `tests/integration/test_real_backend_smoke.py` runs PyTorch on bus.jpg in the `Real Backend Smoke` CI job, delivered by m2's `real-backend-smoke`; (ii) "OpenVINO is at 0%" is FALSE — it is 21%, and the reason it is only 21% turned out to be far worse than low coverage: the backend could not run AT ALL on OpenVINO >=2025, see box 1; (iii) "the integration tier is gated on one developer's home directory" is FALSE — `tests/integration/conftest.py` keys on `YOWO_CACHE_DIR` with a `~/.cache` default, delivered by m1's `ci-weight-fixture`.
