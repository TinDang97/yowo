## A2 [which]
- asked: all of them, then measuring which lie · probe: check each against what executed
- if wrong: found 2026-09-16: `format` reports the request (`backend_type.value`, lines 215 and 264); `model_size_mb` is 5.354 for every format because `_get_model_size_mb` stats the source `.pt` (which is itself 5.354 MB); `device` is honest, read from `engine.selection.device_type` at line 170; the early return at line 223 hardcodes `device="unknown"` although `device` is bound at that point
- answered: confirm

## A3 [when]
- asked: "report nothing rather than something wrong" · probe: is the loaded artifact reachable?
- if wrong: found 2026-09-16: NO. `engine.selection` carries only backend, device_index, device_type, precision, reason; `PyTorchBackend` holds `_spec` but no artifact path; no backend exposes one. So the loaded artifact's size is not obtainable from inside this node's scope for any non-pytorch backend.
- answered: confirm

- answered: confirm

## A15 [when]
